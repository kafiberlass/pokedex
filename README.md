# Покедекс

Справочник покемонов на данных [PokeAPI](https://pokeapi.co/): список, поиск и карточка покемона.

## Возможности

- Список покемонов: карточки с изображением, номером, типами (цвет карточки по типу) и формами
- Поиск покемона по имени — найденный добавляется в список
- Светлая и тёмная тема
- Кэширование списка в localStorage: при повторном открытии данные не запрашиваются заново
- Отмена устаревших запросов через AbortController, скелетоны во время загрузки
- Оптимизация перерисовок: `React.memo`, `useMemo`, локальное состояние поля поиска

## Стек

React 18, Redux (actions, reducer, selectors), Context API для темы, Fetch API, localStorage

## Запуск

```bash
yarn install
yarn start
```

Приложение откроется на http://localhost:3000.
